# Security Policy

## Supported versions

Tinfoil Passkey Kit is pre-1.0. Security fixes are provided for the latest
tagged prerelease only. Upgrade to the newest version before reporting an issue
that may already be fixed.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
vulnerability reporting form:

https://github.com/tinfoilsh/tinfoil-passkey-kit/security/advisories/new

Include the affected version, platform, reproduction steps, and potential
impact. We will acknowledge the report through the private advisory and
coordinate disclosure there.

For usage questions and non-sensitive bugs, use the public issue tracker:

https://github.com/tinfoilsh/tinfoil-passkey-kit/issues
